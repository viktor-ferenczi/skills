# Process & Quality

- **TDD** (Test-Driven Development) — Red → green → refactor; write the failing test first, then the minimal code to pass, then clean up.
- **Boy Scout Rule** — Leave the code a little cleaner than you found it; small opportunistic cleanups, not drive-by rewrites.
- **Code Review** — All changes get a second pair of eyes; review for correctness first, style last.
- **Small, Focused Changes** — Commits and PRs should do one thing; small diffs are reviewable, revertable, and bisectable.
- **CI** (Continuous Integration) — Merge frequently; every change is built and tested automatically before it lands.
- **Refactor Continuously** — Improve structure in small safe steps backed by tests, rather than big-bang rewrites.
