# Coding Habits

- **Readability First** — Code is read far more often than written; optimize for the next reader.
- **Explicit over Implicit** — Make intent, dependencies, and side effects visible; avoid hidden magic.
- **Immutability by Default** — Prefer immutable data; mutate only where necessary and locally.
- **Guard Clauses** — Handle edge cases and errors early and return, keeping the happy path unindented.
- **Meaningful Names** — Names should say what a thing is or does; if a name needs a comment, rename it.
- **Comments Explain Why** — Code shows *what*; comments capture *why* — rationale, trade-offs, gotchas.
- **Avoid Premature Optimization** — Measure first; optimize only proven hot spots, and keep the readable version nearby.
