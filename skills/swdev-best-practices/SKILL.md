# Software Development Best Practices

Apply these principles while designing, writing, and reviewing code.
Read the linked document only when a principle in that group needs clarification.

- **Core principles**: YAGNI, KISS, DRY, SSOT, Fail Fast, Throw Early Catch Late, PoLA — [core-principles.md](core-principles.md)
- **Design & architecture**: SOLID, SoC, LoD, Composition over Inheritance, GRASP, Libraries over Frameworks, Convention over Configuration, Twelve-Factor App — [design-architecture.md](design-architecture.md)
- **Process & quality**: TDD, Boy Scout Rule, Code Review, Small Focused Changes, CI, Continuous Refactoring — [process-quality.md](process-quality.md)
- **Coding habits**: Readability First, Explicit over Implicit, Immutability by Default, Guard Clauses, Meaningful Names, Comments Explain Why, No Premature Optimization — [coding-habits.md](coding-habits.md)
